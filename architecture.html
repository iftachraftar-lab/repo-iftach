מבט-על ארכיטקטוני (System High-Level Architecture)

המערכת בנויה כארכיטקטורת Event-Driven Micro-Services מודרנית: הלקוח רץ ישירות בדפדפן (PWA), מתקשר בפרוטוקול HTTPS מאובטח מול שרת ה-API של FastAPI בענן, אשר מפעיל במקביל מודלי ראייה ממוחשבת (Gemini Vision), סוכני שיחה קליניים, ומאגרי נתונים ב-Firestore.

שכבות המערכת (Detailed Layer Breakdown)

2.1 שכבת הממשק (Frontend / PWA)

Alpine.js + Tailwind
  • ריאקטיביות מיידית: מנוהלת ע״י Alpine.js ללא תלות ב-Node.js Build כבד, מה שמבטיח טעינה ראשונית בפחות מחצי שנייה.
  • ספריית אייקונים ייעודית: סט של 24 סמלים דואוטוניים וקטוריים בפורמט SVG Sprite ללא עיוותים.
  • PWA & Offline: Service Worker עם אסטרטגיית Network-First לסנכרון מיידי ועבודה מלאה גם ללא קליטה.
  • i18n & RTL: תמיכה מלאה דו-כיוונית בעברית ואנגלית עם היפוך ממשק מלא.

2.2 שכבת השרת וה-API

FastAPI / Python 3.12
  • אימות Google OAuth 2.0: אימות טוקן JWT חתום מול שרתי גוגל בכל קריאה.
  • שער אישור מנהל (RBAC): משתמש חדש חייב אישור אדמין בדשבורד ייעודי לפני גישה למשאבי ה-AI.
  • אבטחה והגבלת קצב: Rate-Limiting מבוסס חלון זמן למניעת ספאם והתקפות DoS.
  • אלגוריתמיקה מטאבולית: יישום נוסחאות Mifflin-St Jeor לחישוב BMR/TDEE והתאמת מאקרו דינמית.

2.3 מנוע הבינה המלאכותית (Multimodal AI Engine)

מודול מערכת מודל / מנוע תפקיד במערכת ופונקציונליות
זיהוי מנות וצילום צלחת Gemini Vision פירוק הצלחת למרכיבים, הערכת משקלים קלינית, חישוב קלוריות, חלבון, פחמימות ושומן.
סינון אובייקטים שאינם מזון Guardrail Engine דחייה על הסף של פריטים שאינם מזון (רהיטים, חפצים, מסכים) עם אופציית עקיפה ידנית בלבד.
סורק סופר ("האם לקנות?") Vision + Barcode DB ניתוח תמונת מוצר או תווית ערכים בסופר ומתן ציון התאמה (0-100) ליעדי היום.
מאמן תזונה ואימונים אישי Gemini 2.5 Flash ניתוח חלון הצום בזמן אמת, יתרת חלבון חסרה והמלצות מדויקות להשלמת היום.
רשימת קניות חכמה Gemini Structured JSON סריקת החוסרים השבועיים והפקת רשימת קניות ממוינת לפי מחלקות סופר עם שיתוף לוואטסאפ.

תשתית ענן ו-DevOps (GCP me-west1)

Cloud Run (Serverless Container)

קונטיינר Docker אופטימלי עם Scale-to-Zero מוחלט כשהמערכת אינה בשימוש, ויכולת טיפול בעשרות בקשות במקביל לכל מופע (Concurrency 80).

פריסה רציפה (CI/CD Deployment)

בנייה ופריסה אוטומטיות ישירות ממאגר ה-Git באמצעות Google Cloud Build ללא השבתה (Zero-Downtime Rolling Update).

ניהול סודות ואבטחה (Secret Manager)

אפס מפתחות רגישים בקוד המקור. כל מפתחות ה-API ומזהי ה-OAuth נטענים דינמית בזמן ריצה דרך שירותי IAM של גוגל.

ניטור שגיאות ומדדי ביצועים

Cloud Logging ו-Cloud Monitoring בזמן אמת לאיתור חריגות, קריאות שגויות וזמני תגובת AI.
